# Pseudocoder
A compiler built in Ruby that recognizes code from a programming language such as Javascript and turns it into English pseudocode that anyone can understand. Pseudocoder will help anyone who wants a better understanding of their code.

To view the main compiler code, look in `app/services/compiler`

A CLI prototype version is in `bin/pseudocoder`
